# Coroli Camera Monitor
Android app: external monitor for Sony A7III and other cameras. Coroli Alexandru Photography.

Upload this project to GitHub -> Actions -> "Build APK" -> download the APK artifact.

## Wi-Fi
On the camera enable smartphone connection (Ctrl w/ Smartphone), connect the phone to the camera's Wi-Fi, press Wi-Fi in the app.

## USB
Step 1 (done): detects UVC devices. Step 2: UVC preview.
